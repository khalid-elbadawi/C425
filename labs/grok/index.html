    Lab Material: Introduction to Pthreads in C++

    Objective

    This lab introduces you to the Pthreads (POSIX Threads) library in C++, emphasizing thread creation and the advantages of parallelism. By the end, you’ll be able to create threads, pass arguments to them, and understand how parallelism can enhance performance through a practical example.

    Prerequisites

    • Basic understanding of C++ (functions, pointers, etc.).
    • Familiarity with compiling and running C++ programs in a Unix-like environment (e.g., Linux).
    • A multi-core system to observe parallelism benefits.

    1. Thread Creation

    What is a Thread?

    A thread is a unit of execution within a program that runs concurrently with other threads. Unlike separate processes, threads share the same memory space, enabling efficient communication but requiring careful management to avoid conflicts.

    Why Use Threads?

    Threads enable multiple tasks to run simultaneously, leveraging multi-core processors to improve performance. For instance, a game might use one thread for graphics and another for physics calculations.

    Creating a Thread with Pthreads

    The pthread_create function is used to spawn a new thread. For simplicity, we’ll use default attributes (passing nullptr as the second argument). Here’s a step-by-step guide:

    Step-by-Step Example

    1. Include Headers: Use <pthread.h> for Pthreads and <iostream> for output.
    2. Define a Thread Function: It must return void* and take a void* argument.
    3. Create the Thread: Call pthread_create with a thread identifier, attributes, function, and argument.
    4. Wait for Completion: Use pthread_join to wait for the thread to finish.

    Example Code

    #include <pthread.h>
#include <iostream>

void* say_hello(void* arg) {
    std::cout << "Hello from the thread!\n";
    return nullptr;
}

int main() {
    pthread_t thread_id;
    pthread_create(&thread_id, nullptr, say_hello, nullptr); // Default attributes
    pthread_join(thread_id, nullptr); // Wait for thread to finish
    std::cout << "Main thread finished.\n";
    return 0;
}

    Compile and Run

    g++ -o hello hello.cpp -lpthread
./hello

    Sample Output

    Hello from the thread!
Main thread finished.

    Diagram: Thread Creation Flow

    graph TD
    A[Main Thread] -->|pthread_create| B[New Thread]
    B -->|Runs say_hello| C[Prints "Hello"]
    A -->|pthread_join| D[Waits for New Thread]
    D --> E[Prints "Main finished"]

    Passing Arguments to a Thread

    Threads often need data to perform tasks. Since pthread_create accepts a void* argument, you can pass any data type by casting it.

    Example: Passing an Integer

    #include <pthread.h>
#include <iostream>

void* print_number(void* arg) {
    int* number = static_cast<int*>(arg);
    std::cout << "Thread received: " << *number << "\n";
    return nullptr;
}

int main() {
    pthread_t thread_id;
    int value = 100;
    pthread_create(&thread_id, nullptr, print_number, &value);
    pthread_join(thread_id, nullptr);
    std::cout << "Main thread done.\n";
    return 0;
}

    Compile and Run

    g++ -o number number.cpp -lpthread
./number

    Sample Output

    Thread received: 100
Main thread done.

    Tips

    • Use static_cast to safely convert void* back to the original type.
    • Pass the address of the data (e.g., &value) to pthread_create.

    2. Power of Parallelism

    Objective

    To showcase parallelism’s benefits, we’ll compute prime numbers in a range—first sequentially, then in parallel—and compare their performance.

    Step 1: Define a CPU-Intensive Function (isPrime)

    We’ll check if a number is prime (only divisible by 1 and itself).

    Algorithm

    1. If the number < 2, return false.
    2. For each integer i from 2 to √(number):
    3. If number % i == 0, return false.
    4. Return true if no divisors are found.

    Code

    #include <cmath>

bool isPrime(int num) {
    if (num < 2) return false;
    for (int i = 2; i <= std::sqrt(num); ++i) {
        if (num % i == 0) return false;
    }
    return true;
}

    Step 2: Sequential Prime Checking

    A single thread checks all numbers in a range.

    Code

    #include <vector>
#include <chrono>

void sequentialPrimeCheck(int start, int end, std::vector<bool>& results) {
    auto start_time = std::chrono::high_resolution_clock::now();
    for (int i = start; i < end; ++i) {
        results[i - start] = isPrime(i);
    }
    auto end_time = std::chrono::high_resolution_clock::now();
    std::chrono::duration<double> elapsed = end_time - start_time;
    std::cout << "Sequential time: " << elapsed.count() << " seconds\n";
}

    Diagram: Sequential Execution

    graph TD
    A[Main Thread] --> B[Checks 0 to N-1]
    B -->|Time: T| C[Results Stored]

    Step 3: Parallel Prime Checking

    Multiple threads divide the range, each processing a chunk.

    Code

    #include <pthread.h>
#include <vector>

struct ThreadData {
    int start, end;
    std::vector<bool>* results;
};

void* parallelPrimeCheck(void* arg) {
    ThreadData* data = static_cast<ThreadData*>(arg);
    for (int i = data->start; i < data->end; ++i) {
        (*data->results)[i - data->start] = isPrime(i);
    }
    return nullptr;
}

void runParallel(int num_threads, int start, int end, std::vector<bool>& results) {
    auto start_time = std::chrono::high_resolution_clock::now();
    std::vector<pthread_t> threads(num_threads);
    std::vector<ThreadData> thread_data(num_threads);
    int chunk_size = (end - start) / num_threads;

    for (int i = 0; i < num_threads; ++i) {
        thread_data[i].start = start + i * chunk_size;
        thread_data[i].end = (i == num_threads - 1) ? end : start + (i + 1) * chunk_size;
        thread_data[i].results = &results;
        pthread_create(&threads[i], nullptr, parallelPrimeCheck, &thread_data[i]);
    }
    for (auto& thread : threads) {
        pthread_join(thread, nullptr);
    }
    auto end_time = std::chrono::high_resolution_clock::now();
    std::chrono::duration<double> elapsed = end_time - start_time;
    std::cout << "Parallel time (" << num_threads << " threads): " << elapsed.count() << " seconds\n";
}

    Diagram: Parallel Execution

    graph TD
    A[Main Thread] -->|Splits Range| B[Thread 1: 0 to N/4]
    A --> C[Thread 2: N/4 to N/2]
    A --> D[Thread 3: N/2 to 3N/4]
    A --> E[Thread 4: 3N/4 to N]
    B & C & D & E -->|Time: ~T/4| F[Results Combined]

    Step 4: Complete Program

    Combine everything to compare sequential vs. parallel performance.

    Full Code

    #include <iostream>
#include <vector>
#include <chrono>
#include <pthread.h>
#include <cmath>

bool isPrime(int num) {
    if (num < 2) return false;
    for (int i = 2; i <= std::sqrt(num); ++i) {
        if (num % i == 0) return false;
    }
    return true;
}

void sequentialPrimeCheck(int start, int end, std::vector<bool>& results) {
    auto start_time = std::chrono::high_resolution_clock::now();
    for (int i = start; i < end; ++i) {
        results[i - start] = isPrime(i);
    }
    auto end_time = std::chrono::high_resolution_clock::now();
    std::chrono::duration<double> elapsed = end_time - start_time;
    std::cout << "Sequential time: " << elapsed.count() << " seconds\n";
}

struct ThreadData {
    int start, end;
    std::vector<bool>* results;
};

void* parallelPrimeCheck(void* arg) {
    ThreadData* data = static_cast<ThreadData*>(arg);
    for (int i = data->start; i < data->end; ++i) {
        (*data->results)[i - data->start] = isPrime(i);
    }
    return nullptr;
}

void runParallel(int num_threads, int start, int end, std::vector<bool>& results) {
    auto start_time = std::chrono::high_resolution_clock::now();
    std::vector<pthread_t> threads(num_threads);
    std::vector<ThreadData> thread_data(num_threads);
    int chunk_size = (end - start) / num_threads;

    for (int i = 0; i < num_threads; ++i) {
        thread_data[i].start = start + i * chunk_size;
        thread_data[i].end = (i == num_threads - 1) ? end : start + (i + 1) * chunk_size;
        thread_data[i].results = &results;
        pthread_create(&threads[i], nullptr, parallelPrimeCheck, &thread_data[i]);
    }
    for (auto& thread : threads) {
        pthread_join(thread, nullptr);
    }
    auto end_time = std::chrono::high_resolution_clock::now();
    std::chrono::duration<double> elapsed = end_time - start_time;
    std::cout << "Parallel time (" << num_threads << " threads): " << elapsed.count() << " seconds\n";
}

int main() {
    const int START = 0;
    const int END = 100000; // Range: 0 to 99999
    const int NUM_THREADS = 4; // Adjust based on your CPU cores

    std::vector<bool> seq_results(END - START);
    std::vector<bool> par_results(END - START);

    sequentialPrimeCheck(START, END, seq_results);
    runParallel(NUM_THREADS, START, END, par_results);

    // Hypothetical times for demonstration (replace with actual output)
    double seq_time = 10.5; // Example sequential time
    double par_time = 2.8;  // Example parallel time
    double speedup = seq_time / par_time;
    double efficiency = speedup / NUM_THREADS;
    std::cout << "Speedup: " << speedup << "\n";
    std::cout << "Efficiency: " << efficiency << "\n";

    return 0;
}

    Compile and Run

    g++ -o prime prime.cpp -lpthread
./prime

    Sample Output (Hypothetical)

    Sequential time: 10.5 seconds
Parallel time (4 threads): 2.8 seconds
Speedup: 3.75
Efficiency: 0.9375

    Explanation

    • Speedup: Sequential time / Parallel time. Ideal speedup with 4 threads is 4.
    • Efficiency: Speedup / Number of threads. Measures thread utilization (max 1.0).
