    Lab (6): Mastering Work-Sharing Directives

    Lab Overview

    Welcome to the second part of our OpenMP adventure! In this lab, you'll dive into the exciting world of work-sharing directives, focusing on the #pragma omp for directive, loop scheduling strategies, and the #pragma omp single directive. Through hands-on exercises, you'll learn to distribute loop iterations across threads, explore scheduling policies, and manage single-threaded execution within parallel regions. We'll use the Leibniz algorithm to estimate π, adding a mathematical twist to our parallel programming journey.

    Lab Objectives

    By the end of this lab, you will be able to:

    1. Apply the #pragma omp for directive to parallelize loops effectively.
    2. Identify and mitigate loop-carried dependencies.
    3. Implement different loop scheduling strategies (static, dynamic, guided).
    4. Use the #pragma omp single directive for controlled single-thread execution.
    5. Develop parallel algorithms for π estimation (Leibniz method), sorting, and matrix operations.
    6. Analyze performance impacts of scheduling strategies and thread counts.

    1. Work-Sharing Directives

    In the previous lab, you manually distributed loop iterations across threads by calculating start and end indices based on thread IDs, which required careful bookkeeping and could lead to errors or load imbalance. The #pragma omp for directive simplifies this process by automatically dividing loop iterations among threads, reducing code complexity and improving maintainability. This work-sharing approach not only saves you from manual index calculations but also allows OpenMP to optimize distribution based on scheduling strategies, making your parallel programs more efficient and scalable.

    Work-sharing directives distribute tasks among threads within a parallel region. The #pragma omp for directive is your primary tool for parallelizing loops, dividing iterations across threads for efficient computation.

    1.1 The for Directive

    The #pragma omp for directive splits loop iterations among threads. It must be used within a parallel region and requires:

    • A determinable loop trip count.
    • An integer or pointer-type loop variable.
    • Unchanging loop bounds during execution.

    Syntax:

    #pragma omp for [clauses]
for (init; condition; increment)

    Example 1.1: Basic Parallel For

    This example demonstrates separate parallel and for directives.

    #include <cstdio>
#include <omp.h>

int main() {
    const int n = 16;
    int arr[n];

    printf("=== Method 1: Separate parallel and for directives ===\n");
    #pragma omp parallel num_threads(4)
    {
        #pragma omp for
        for (int i = 0; i < n; i++) {
            arr[i] = 2 * i + 1;
            printf("Thread %d processing i = %d arr[%d] = %d\n",
                   omp_get_thread_num(), i, i, arr[i]);
        }
    }
    return 0;
}

    Example 1.2: Combined Parallel For

    This example uses the combined parallel for directive for brevity.

    #include <cstdio>
#include <omp.h>

int main() {
    const int n = 16;
    int arr[n];

    printf("=== Method 2: Combined parallel for directive ===\n");
    #pragma omp parallel for num_threads(4)
    for (int i = 0; i < n; i++) {
        arr[i] = 2 * i + 1;
        printf("Thread %d processing i = %d arr[%d] = %d\n",
               omp_get_thread_num(), i, i, arr[i]);
    }
    return 0;
}

    1.2 Loop-Carried Dependencies

    Loops with dependencies between iterations (loop-carried dependencies) cannot be safely parallelized without special handling, as iterations may depend on previous results.

    Example 1.3: Fibonacci Sequence - Incorrect Parallelization

    This example shows why parallelizing a Fibonacci sequence computation fails due to dependencies.

    #include <cstdio>
#include <omp.h>

int main() {
    const int n = 30;
    long fib[n];

    // Serial version (correct)
    printf("=== Serial Fibonacci ===\n");
    fib[0] = fib[1] = 1;
    for (int i = 2; i < n; i++) {
        fib[i] = fib[i-1] + fib[i-2];
    }
    printf("Serial result: ");
    for (int i = 0; i < n; i++) {
        printf("%ld ", fib[i]);
    }
    printf("\n");

    // Parallel version (incorrect - has loop-carried dependency)
    printf("=== Parallel Fibonacci (INCORRECT) ===\n");

    // reset old values
    fib[0] = fib[1] = 1;
    for (int i=2; i<n; i++) fib[i] = 0;

    #pragma omp parallel for num_threads(4)
    for (int i = 2; i < n; i++)
        fib[i] = fib[i-1] + fib[i-2];
    printf("Parallel result: ");
    for (int i = 0; i < n; i++) {
        printf("%ld ", fib[i]);
    }
    printf("\n");
    return 0;
}

    2. Tutorial 1: Estimating \(\pi\) with the Leibniz Algorithm

    The Leibniz formula for \(\pi\) is a series: \(\pi/4 = 1 - 1/3 + 1/5 - 1/7 + \cdots\). We'll compute this sum in serial and parallel versions, addressing synchronization challenges.

    2.1 Serial \(\pi\) Estimation

    This example computes \(\pi\) using the Leibniz series sequentially.

    #include <cstdio>
#include <chrono>
#include <cmath>

int main() {
    long n = 100000000; // Number of terms
    double sum = 0.0;

    auto start = std::chrono::high_resolution_clock::now();
    for (long i = 0; i < n; i++) {
        sum += (i % 2 == 0 ? 1.0 : -1.0) / (2.0 * i + 1);
    }
    double pi_estimate = 4.0 * sum;

    auto end = std::chrono::high_resolution_clock::now();
    auto duration = std::chrono::duration_cast<std::chrono::milliseconds>(end - start);

    printf("Serial π estimation\n");
    printf("Estimated π = %.10f\n", pi_estimate);
    printf("Actual π = %.10f\n", M_PI);
    printf("Error = %.10f\n", std::fabs(pi_estimate - M_PI));
    printf("Time = %ld ms\n", duration.count());
    return 0;
}

    2.2 Parallel \(\pi\) Estimation - Incorrect Implementation

    This version has a race condition due to shared access to sum.

    #include <cstdio>
#include <omp.h>
#include <chrono>
#include <cmath>

int main() {
    long n = 100000000;
    double sum = 0.0;

    auto start = std::chrono::high_resolution_clock::now();
    #pragma omp parallel for num_threads(4)
    for (long i = 0; i < n; i++) {
        sum += (i % 2 == 0 ? 1.0 : -1.0) / (2.0 * i + 1); // Race condition!
    }
    double pi_estimate = 4.0 * sum;

    auto end = std::chrono::high_resolution_clock::now();
    auto duration = std::chrono::duration_cast<std::chrono::milliseconds>(end - start);

    printf("Parallel π estimation (INCORRECT)\n");
    printf("Estimated π = %.10f\n", pi_estimate);
    printf("Actual π = %.10f\n", M_PI);
    printf("Error = %.10f\n", std::fabs(pi_estimate - M_PI));
    printf("Time = %ld ms\n", duration.count());
    return 0;
}

    2.3 Parallel \(\pi\) Estimation - Using Private Variables and Critical Section

    This alternative uses private variables and a critical section for synchronization.

    #include <cstdio>
#include <omp.h>
#include <chrono>
#include <cmath>

int main() {
    long n = 100000000;
    double sum = 0.0;

    auto start = std::chrono::high_resolution_clock::now();
    #pragma omp parallel num_threads(4)
    {
        double local_sum = 0.0;
        #pragma omp for
        for (long i = 0; i < n; i++) {
            local_sum += (i % 2 == 0 ? 1.0 : -1.0) / (2.0 * i + 1);
        }
        #pragma omp critical
        sum += local_sum;
    }
    double pi_estimate = 4.0 * sum;

    auto end = std::chrono::high_resolution_clock::now();
    auto duration = std::chrono::duration_cast<std::chrono::milliseconds>(end - start);

    printf("Parallel π estimation with critical section\n");
    printf("Estimated π = %.10f\n", pi_estimate);
    printf("Actual π = %.10f\n", M_PI);
    printf("Error = %.10f\n", std::fabs(pi_estimate - M_PI));
    printf("Time = %ld ms\n", duration.count());
    return 0;
}

    2.4 Parallel \(\pi\) Estimation - Correct Implementation with Reduction

    Using the reduction clause avoids race conditions.

    #include <cstdio>
#include <omp.h>
#include <chrono>
#include <cmath>

int main() {
    long n = 100000000;
    double sum = 0.0;

    auto start = std::chrono::high_resolution_clock::now();
    #pragma omp parallel for num_threads(4) reduction(+:sum)
    for (long i = 0; i < n; i++) {
        sum += (i % 2 == 0 ? 1.0 : -1.0) / (2.0 * i + 1);
    }
    double pi_estimate = 4.0 * sum;

    auto end = std::chrono::high_resolution_clock::now();
    auto duration = std::chrono::duration_cast<std::chrono::milliseconds>(end - start);

    printf("Parallel π estimation (CORRECT)\n");
    printf("Estimated π = %.10f\n", pi_estimate);
    printf("Actual π = %.10f\n", M_PI);
    printf("Error = %.10f\n", std::fabs(pi_estimate - M_PI));
    printf("Time = %ld ms\n", duration.count());
    return 0;
}

    3. Loop Scheduling

    OpenMP provides several scheduling strategies to control how loop iterations are distributed among threads. The choice of schedule significantly impacts performance and load balancing, especially when iterations have variable workloads. Key scheduling strategies include:

    Schedule Type Behavior Best Use Case
    static Iterations divided into equal chunks before execution Uniform workloads
    dynamic Iterations assigned on-demand as threads become free Irregular/variable workloads
    guided Chunk sizes start large and decrease exponentially during execution Balancing overhead and load balancing
    runtime Schedule determined by OMP_SCHEDULE environment variable Runtime customization

    Example 3.1: Comparing Scheduling Strategies

    This example demonstrates the impact of scheduling on performance.

    #include <cstdio>
#include <omp.h>
#include <chrono>
#include <cmath>
#include <string>

double compute_function(int i) {
    double result = 0.0;
    for (int j = 0; j < i * 1000; j++) { // Variable workload
        result += std::sin(j * 0.1);
    }
    return result;
}

void test_schedule(const char* schedule_name, int n, int num_threads) {
    printf("Testing %s schedule\n", schedule_name);
    double sum = 0.0;
    auto start = std::chrono::high_resolution_clock::now();

    if (std::string(schedule_name) == "static") {
        #pragma omp parallel for num_threads(num_threads) schedule(static)
        for (int i = 0; i < n; i++) {
            sum += compute_function(i);
            printf("Thread %d processed iteration %d\n",
                   omp_get_thread_num(), i);
        }
    } else if (std::string(schedule_name) == "dynamic") {
        #pragma omp parallel for num_threads(num_threads) schedule(dynamic, 2)
        for (int i = 0; i < n; i++) {
            sum += compute_function(i);
            printf("Thread %d processed iteration %d\n",
                   omp_get_thread_num(), i);
        }
    } else if (std::string(schedule_name) == "guided") {
        #pragma omp parallel for num_threads(num_threads) schedule(guided)
        for (int i = 0; i < n; i++) {
            sum += compute_function(i);
            printf("Thread %d processed iteration %d\n",
                   omp_get_thread_num(), i);
        }
    }

    auto end = std::chrono::high_resolution_clock::now();
    auto duration = std::chrono::duration_cast<std::chrono::milliseconds>(end - start);
    printf("Time for %s schedule: %ld ms\n", schedule_name, duration.count());
}

int main() {
    const int n = 20;
    const int num_threads = 4;
    printf("Comparing scheduling strategies with %d threads and %d iterations\n",
           num_threads, n);
    test_schedule("static", n, num_threads);
    test_schedule("dynamic", n, num_threads);
    test_schedule("guided", n, num_threads);
    return 0;
}

    4. The Single Directive

    The #pragma omp single directive ensures a block is executed by only one thread, with others waiting at an implicit barrier.

    Syntax:

    #pragma omp single [clauses]
structured block

    Example 4.1: Basic Single Directive

    This example shows single-threaded execution within a parallel region.

    #include <cstdio>
#include <omp.h>

int main() {
    printf("Before parallel region\n");
    #pragma omp parallel num_threads(4)
    {
        printf("Thread %d before single region\n", omp_get_thread_num());
        #pragma omp single
        {
            printf("Only thread %d executes this single block\n",
                   omp_get_thread_num());
            for (int i = 0; i < 3; i++) {
                printf("Single thread working... step %d\n", i + 1);
            }
        }
        printf("Thread %d after single region\n", omp_get_thread_num());
    }
    return 0;
}

    Example 4.2: Single Directive with Copyprivate

    The copyprivate clause broadcasts a variable's value to all threads.

    #include <cstdio>
#include <omp.h>

int main() {
    int x = 5;
    printf("Initial x = %d\n", x);
    #pragma omp parallel num_threads(4) default(none) private(x)
    {
        printf("Thread %d before single: x = %d (uninitialized)\n",
               omp_get_thread_num(), x);
        #pragma omp single copyprivate(x)
        {
            x = 42;
            printf("Thread %d in single block set x = %d\n",
                   omp_get_thread_num(), x);
        }
        printf("Thread %d after single: x = %d\n",
               omp_get_thread_num(), x);
    }
    printf("After parallel region: x = %d\n", x);
    return 0;
}

    5. Tutorial 2: Bubble Sort and Odd-Even Transposition Sort

    Sorting algorithms provide a great context for exploring parallelization challenges. We'll compare serial and parallel sorting methods.

    5.1 Serial Bubble Sort

    This is a straightforward bubble sort implementation.

    #include <cstdio>
#include <vector>
#include <chrono>
#include <random>
#include <algorithm>

void bubble_sort_serial(std::vector<int>& arr) {
    int n = arr.size();
    for (int i = 0; i < n - 1; i++) {
        for (int j = 0; j < n - i - 1; j++) {
            if (arr[j] > arr[j + 1]) {
                std::swap(arr[j], arr[j + 1]);
            }
        }
    }
}

int main() {
    const int n = 10000;
    std::vector<int> arr(n);
    std::random_device rd;
    std::mt19937 gen(rd());
    std::uniform_int_distribution<> dis(1, 1000);
    for (int& val : arr) {
        val = dis(gen);
    }

    auto start = std::chrono::high_resolution_clock::now();
    bubble_sort_serial(arr);
    auto end = std::chrono::high_resolution_clock::now();
    auto duration = std::chrono::duration_cast<std::chrono::milliseconds>(end - start);

    printf("Serial bubble sort time: %ld ms\n", duration.count());
    bool is_sorted = std::is_sorted(arr.begin(), arr.end());
    printf("Array is sorted: %s\n", is_sorted ? "Yes" : "No");
    return 0;
}

    5.2 Serial Odd-Even Transposition Sort

    This algorithm alternates comparisons between odd and even indices, making it more parallelizable.

    #include <cstdio>
#include <vector>
#include <chrono>
#include <random>
#include <algorithm>

void odd_even_sort_serial(std::vector<int>& arr) {
    int n = arr.size();
    bool sorted = false;
    while (!sorted) {
        sorted = true;
        // Odd phase
        for (int i = 1; i < n - 1; i += 2) {
            if (arr[i] > arr[i + 1]) {
                std::swap(arr[i], arr[i + 1]);
                sorted = false;
            }
        }
        // Even phase
        for (int i = 0; i < n - 1; i += 2) {
            if (arr[i] > arr[i + 1]) {
                std::swap(arr[i], arr[i + 1]);
                sorted = false;
            }
        }
    }
}

int main() {
    const int n = 10000;
    std::vector<int> arr(n);
    std::random_device rd;
    std::mt19937 gen(rd());
    std::uniform_int_distribution<> dis(1, 1000);
    for (int& val : arr) {
        val = dis(gen);
    }

    auto start = std::chrono::high_resolution_clock::now();
    odd_even_sort_serial(arr);
    auto end = std::chrono::high_resolution_clock::now();
    auto duration = std::chrono::duration_cast<std::chrono::milliseconds>(end - start);

    printf("Serial odd-even sort time: %ld ms\n", duration.count());
    bool is_sorted = std::is_sorted(arr.begin(), arr.end());
    printf("Array is sorted: %s\n", is_sorted ? "Yes" : "No");
    return 0;
}

    5.3 Parallel Odd-Even Transposition Sort

    This version parallelizes the odd and even phases.

    #include <cstdio>
#include <vector>
#include <chrono>
#include <random>
#include <algorithm>
#include <omp.h>

void odd_even_sort_parallel(std::vector<int>& arr, int num_threads) {
    int n = arr.size();
    for (int phase = 0; phase < n; phase++) {
        if (phase % 2 == 1) {
            #pragma omp parallel for num_threads(num_threads)
            for (int i = 1; i < n - 1; i += 2) {
                if (arr[i] > arr[i + 1]) {
                    std::swap(arr[i], arr[i + 1]);
                }
            }
        } else {
            #pragma omp parallel for num_threads(num_threads)
            for (int i = 0; i < n - 1; i += 2) {
                if (arr[i] > arr[i + 1]) {
                    std::swap(arr[i], arr[i + 1]);
                }
            }
        }
    }
}

int main() {
    const int n = 10000;
    const int num_threads = 4;
    std::vector<int> arr(n);
    std::random_device rd;
    std::mt19937 gen(rd());
    std::uniform_int_distribution<> dis(1, 1000);
    for (int& val : arr) {
        val = dis(gen);
    }

    auto start = std::chrono::high_resolution_clock::now();
    odd_even_sort_parallel(arr, num_threads);
    auto end = std::chrono::high_resolution_clock::now();
    auto duration = std::chrono::duration_cast<std::chrono::milliseconds>(end - start);

    printf("Parallel odd-even sort time: %ld ms\n", duration.count());
    bool is_sorted = std::is_sorted(arr.begin(), arr.end());
    printf("Array is sorted: %s\n", is_sorted ? "Yes" : "No");
    return 0;
}

    6. Tutorial 3: Matrix-Vector Multiplication

    Matrix-vector multiplication is highly parallelizable due to independent row computations.

    6.1 Serial Matrix-Vector Multiplication

    This is the baseline serial implementation.

    #include <cstdio>
#include <vector>
#include <chrono>
#include <random>
#include <iomanip>

void matrix_vector_multiply_serial(const std::vector<std::vector<double>>& matrix,
                                   const std::vector<double>& vector,
                                   std::vector<double>& result) {
    int m = matrix.size();
    int n = matrix[0].size();
    for (int i = 0; i < m; i++) {
        result[i] = 0.0;
        for (int j = 0; j < n; j++) {
            result[i] += matrix[i][j] * vector[j];
        }
    }
}

void print_vector(const std::vector<double>& vec, const std::string& name) {
    printf("%s (first 10 elements): ", name.c_str());
    for (size_t i = 0; i < std::min((size_t)10, vec.size()); i++) {
        printf("%8.2f ", vec[i]);
    }
    printf("\n");
}

int main() {
    const int m = 2000;
    const int n = 2000;
    std::vector<std::vector<double>> matrix(m, std::vector<double>(n));
    std::vector<double> vector(n), result(m);
    std::random_device rd;
    std::mt19937 gen(rd());
    std::uniform_real_distribution<> dis(0.0, 10.0);

    for (int i = 0; i < m; i++) {
        for (int j = 0; j < n; j++) {
            matrix[i][j] = dis(gen);
        }
    }
    for (int i = 0; i < n; i++) {
        vector[i] = dis(gen);
    }

    auto start = std::chrono::high_resolution_clock::now();
    matrix_vector_multiply_serial(matrix, vector, result);
    auto end = std::chrono::high_resolution_clock::now();
    auto duration = std::chrono::duration_cast<std::chrono::milliseconds>(end - start);

    print_vector(result, "Result");
    printf("Serial matrix-vector time: %ld ms\n", duration.count());
    return 0;
}

    6.2 Parallel Matrix-Vector Multiplication

    This version parallelizes the outer loop.

    #include <cstdio>
#include <vector>
#include <chrono>
#include <random>
#include <iomanip>
#include <omp.h>

void matrix_vector_multiply_parallel(const std::vector<std::vector<double>>& matrix,
                                    const std::vector<double>& vector,
                                    std::vector<double>& result,
                                    int num_threads) {
    int m = matrix.size();
    int n = matrix[0].size();
    #pragma omp parallel for num_threads(num_threads) default(none) shared(matrix, vector, result, m, n)
    for (int i = 0; i < m; i++) {
        result[i] = 0.0;
        for (int j = 0; j < n; j++) {
            result[i] += matrix[i][j] * vector[j];
        }
        if (m <= 20) {
            printf("Thread %d computed row %d\n", omp_get_thread_num(), i);
        }
    }
}

void print_vector(const std::vector<double>& vec, const std::string& name) {
    printf("%s (first 10 elements): ", name.c_str());
    for (size_t i = 0; i < std::min((size_t)10, vec.size()); i++) {
        printf("%8.2f ", vec[i]);
    }
    printf("\n");
}

int main() {
    const int m = 2000;
    const int n = 2000;
    const int num_threads = 4;
    std::vector<std::vector<double>> matrix(m, std::vector<double>(n));
    std::vector<double> vector(n), result(m);
    std::random_device rd;
    std::mt19937 gen(rd());
    std::uniform_real_distribution<> dis(0.0, 10.0);

    for (int i = 0; i < m; i++) {
        for (int j = 0; j < n; j++) {
            matrix[i][j] = dis(gen);
        }
    }
    for (int i = 0; i < n; i++) {
        vector[i] = dis(gen);
    }

    auto start = std::chrono::high_resolution_clock::now();
    matrix_vector_multiply_parallel(matrix, vector, result, num_threads);
    auto end = std::chrono::high_resolution_clock::now();
    auto duration = std::chrono::duration_cast<std::chrono::milliseconds>(end - start);

    print_vector(result, "Result");
    printf("Parallel matrix-vector time: %ld ms\n", duration.count());
    return 0;
}

    7. Advanced Synchronization

    Synchronization ensures threads coordinate correctly, avoiding race conditions and ensuring data consistency.

    7.1 Barrier Directive

    The #pragma omp barrier directive synchronizes all threads in a parallel region.

    Example 7.1: Using Barriers

    This example demonstrates phased computation with barriers.

    #include <cstdio>
#include <vector>
#include <omp.h>

int main() {
    const int n = 8;
    std::vector<int> a(n), b(n);
    for (int i = 0; i < n; i++) {
        a[i] = i * 2;
    }

    printf("Initial array a: ");
    for (int val : a) {
        printf("%d ", val);
    }
    printf("\n");

    #pragma omp parallel num_threads(4) default(none) shared(a, b, n)
    {
        int thread_id = omp_get_thread_num();
        int num_threads = omp_get_num_threads();
        int start = thread_id * n / num_threads;
        int end = (thread_id + 1) * n / num_threads;

        // Phase 1: Modify array a
        for (int i = start; i < end; i++) {
            a[i] *= 3;
            printf("Thread %d modified a[%d] = %d\n", thread_id, i, a[i]);
        }

        #pragma omp barrier

        // Phase 2: Compute b using neighbor's data
        int neighbor_idx = (thread_id == 0) ? end : start - 1;
        b[thread_id] = a[neighbor_idx];
        printf("Thread %d used a[%d] = %d\n", thread_id, neighbor_idx, b[thread_id]);
    }

    printf("Final array b: ");
    for (int val : b) {
        printf("%d ", val);
    }
    printf("\n");
    return 0;
}

    7.2 Critical vs. Atomic Operations

    This example compares critical and atomic for incrementing a counter.

    #include <cstdio>
#include <omp.h>
#include <chrono>

int main() {
    const int n = 10000000;
    int counter_critical = 0;
    int counter_atomic = 0;

    // Method 1: Critical section
    auto start = std::chrono::high_resolution_clock::now();
    #pragma omp parallel for num_threads(4)
    for (int i = 0; i < n; i++) {
        #pragma omp critical
        counter_critical++;
    }
    auto end = std::chrono::high_resolution_clock::now();
    auto critical_time = std::chrono::duration_cast<std::chrono::milliseconds>(end - start);

    // Method 2: Atomic operation
    start = std::chrono::high_resolution_clock::now();
    #pragma omp parallel for num_threads(4)
    for (int i = 0; i < n; i++) {
        #pragma omp atomic
        counter_atomic++;
    }
    end = std::chrono::high_resolution_clock::now();
    auto atomic_time = std::chrono::duration_cast<std::chrono::milliseconds>(end - start);

    printf("Counter with critical section: %d\n", counter_critical);
    printf("Counter with atomic operation: %d\n", counter_atomic);
    printf("Critical section time: %ld ms\n", critical_time.count());
    printf("Atomic operation time: %ld ms\n", atomic_time.count());
    printf("Speedup using atomic: %.2f x\n", (double)critical_time.count() / atomic_time.count());
    return 0;
}
